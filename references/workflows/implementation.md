# Implementation Workflow Delta

Apply these additions to the core routing flow for code or configuration changes:

- inspect repository instructions and existing changes;
- identify deterministic build, test, type, lint, schema, and diff checks;
- keep one owner for a mutable workspace unless writers are isolated;
- use one capable agent for coupled changes;
- delegate only independent read-only analysis or isolated implementation scopes;
- verify the resulting state, not the agent's completion statement;
- keep commit, push, deployment, and publication as separate authority decisions.
